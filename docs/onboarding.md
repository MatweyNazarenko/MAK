# Практика с подсказками

Вход: приглашение на главной или постоянная кнопка «Помощь».
Четыре шага: необязательный запрос → случайная карта / выбор среди шести изображений → один вопрос для рассмотрения → необязательная заметка.

Закрытие подсказок переносит карту и текст в обычную практику. Повторный вход возвращает к тому же шагу в текущем сеансе. Черновики не записываются автоматически и теряются при перезагрузке страницы. Отказ от приглашения запоминается отдельно в `mak_teacher_guide_seen`; личные заметки используют прежний `mak_teacher_v1`.

Сохранение уважает режим без сохранения, проверяет доступность localStorage и предотвращает повторное сохранение неизменённого текста в рамках этой практики. Завершение без записи не сохраняет черновик.

Ручные проверки:
- Отклонить приглашение, перезагрузить, открыть через помощь.
- Пройти без вопроса; выбрать случайную карту.
- Вернуться назад, выбрать изображение, показать другую шестёрку.
- Переключить подсказку, записать мысль, закрыть обучение, вернуться.
- Сохранить заметку, открыть «Моё», перезагрузить и проверить запись.
- В режиме без сохранения проверить недоступность сохранения.
- Проверить клавиатурный фокус и ширину 360 px.
